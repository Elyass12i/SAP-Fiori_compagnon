Environments

A rule matches a page by text contained in its URL (for example a host name), or by a regular expression written between slashes, such as /sap-dev|:44300/. The SAP client is optional: if it is filled in, the URL must contain sap-client= with that value. The first matching rule wins. The system URL (optional) is the address of this environment’s system, for example https://sap-dev.example.com:44300: it is used by the version comparison, the “Open in” buttons and the SAP log links. Sim. allows error simulation on the environment: tick it only for development systems.
